## 实现与回归

WebUI `src/lib/apis/startup.ts` 同时发起公共配置和 session 查询，session 失败仍返回公共配置用于登录界面；根布局保留登录成功后的配置刷新，避免误用匿名/其他 cookie 身份的配置。校验期间 localStorage token 改变时不应用旧 session。

`getModels` 的连接参数兼容既有对象/null，并接受一次性的设置 Promise。先读取服务端模型，同时等待最新用户设置；直连模型始终在设置成功、且当前配置允许后访问。Promise 在创建时连接拒绝处理，设置失败不发布模型列表。不增加持久缓存、轮询或后台付费调用。
