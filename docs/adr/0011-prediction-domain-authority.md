# ADR-011：预测事实事务由 Alpha 领域服务统一维护

架构任务书原示意由 BFF 直接写入预测、Alpha 负责计算。实现中将预测草稿、冻结与结算事务放在 Alpha 的 `ResearchStore`，让 BFF 和后台 Jobs 复用同一组 Decimal、交易日历、幂等和不可变规则，避免跨语言维护两套金融事实约束。BFF 仍是唯一公开入口，负责登录、CSRF、用户确认及所有者身份；Alpha 内部端点只接受已认证的服务调用，不能由浏览器直接指定 owner。

代价是冻结路径增加一次私网调用，Alpha 成为预测事实的持久化权威；BFF 保留会话/研究事件和身份模块的存储职责。服务超时须使用相同幂等键核对，不绕过领域服务直接补写事实。数据库角色及追加约束同时保护应用和 Jobs 路径。
