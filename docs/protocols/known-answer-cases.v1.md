## K03 — 分红权益与再投资

100美元入场、持有1股；在持有期间有权取得每股2美元分红，除息日收盘98美元，退出102美元：

```text
quantity_after_reinvestment = 1 + 2/98
terminal_value = 102 * (1 + 2/98) = 104.081632653061...
asset_return = 0.040816326531...
benchmark_return = 0.01
excess_return = 0.030816326531...
```

若改为除息日开盘才入场，不能取得该次股息；总收益序列已经计入分红时也不能再次加现金。

## K04 — 拆分不产生虚假收益

100美元入场1股，持有期间发生2:1拆分，退出每股51美元：终值102美元，收益2%。若入场时价格已经是拆分后价格，不再把初始股数乘2。

## K05 — 锁等待与提交确认

deadline=09:15:00 ET：

- 事务09:14开始，09:15:01才取得链头锁：拒绝新预测，不能使用事务起点 now() 通过检查。
- 09:14:59封存检查通过，09:15:02才收到持久提交成功确认：原记录保留，标 late，不能计入准时集合。
- 确认丢失：uncertain；之后重复查询仅返回原 commit，不生成第二组或自动升级准时。
- 用户提供更早 sealed_at：不接受，时间由可信系统产生。

## K06 — 来源数量与 Brier 方向

20证券 × 3 horizons = 60 case，每个 release 有180个来源位置。Phase 1A 计划启用120个来源位置；60个 LLM 位置的 not_enabled 不是失败。

D20 两个已配对 case 的 y 分别为1、0；baseline 均为0.5、quant 均为0.8：

```text
d_1 = (0.8-1)^2 - (0.5-1)^2 = -0.21
d_2 = (0.8-0)^2 - (0.5-0)^2 =  0.39
mean_d = 0.09
```

正差值说明此例 quant 更差。quant unavailable 的 case 不进入配对损失，仍计入该来源计划分母，baseline 成功记录保留。Phase 1A 不自动回退；Phase 1B 仅在有效 quant 和截止时间允许时回退 LLM。

## K09 — 固定窗口停牌政策（Q5 已定稿）

计划周一开盘入场，证券周三才复牌：原入场时段未形成有效价格，case 记 unscorable，保留在计划分母；不可拿周三开盘替代，也不产生“周一价格入场”的收益。

计划 exit 当日停牌，随后收到供应商补发的原 exit_at 官方数据，与复牌日的新价格是两种证据；只有前者可用于结果认定。统一宽限期（原计划 exit_at 起 5 个后续交易日）到期时入场价、出场价或公司行为仍缺失的记 unresolved；此后补齐原时点数据追加 OutcomeRevision。

D1 的宽限期同样从其 exit_at（入场日收盘）起算，不因 horizon 短而豁免，也没有更长的等待时间。
